BELANGRIJK
Een echte PWA-installatie op het startscherm werkt via HTTPS (of localhost).
Een los bestand vanaf Downloads kan wel openen, maar service worker/offline-installatie werkt dan meestal niet.

Snelste gratis route:
1. Upload deze map naar GitHub Pages, Netlify of Vercel.
2. Open de HTTPS-link op je mobiel.
3. Android/Chrome: menu > Toevoegen aan startscherm / App installeren.
4. iPhone/Safari: Deel > Zet op beginscherm.

Daarna staat het COACH-icoon als app op je startscherm.
